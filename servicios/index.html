Servicios

Información útil para una decisión concreta.

Cada trabajo se define por la necesidad que aborda, la evidencia disponible, los entregables y el plazo acordado. La consulta inicial es breve; el relevamiento detallado queda para la etapa de trabajo.

01 · Diagnóstico

Radiografía territorial

Para comprender actores, conflictos, oportunidades y condiciones de un territorio o problema puntual.

Puede incluir
Mapa de actores, antecedentes, señales relevantes y lectura ejecutiva.
Recibís
Un informe con fecha, alcance definido, fuentes utilizadas y conclusiones para la decisión planteada.
Se acuerda antes
Territorio, profundidad, información disponible, formato y plazo.
Consultar este alcance
02 · Estrategia

Análisis estratégico

Para ordenar alternativas, variables críticas y escenarios alrededor de una decisión institucional, política o empresarial.

Puede incluir
Hipótesis de escenario, riesgos, oportunidades y criterios para priorizar cursos de acción.
Recibís
Una lectura ejecutiva alineada con el objetivo y el horizonte temporal acordados.
No reemplaza
Decisiones del equipo ni garantías sobre resultados futuros.
Consultar este alcance
03 · Seguimiento

Monitoreo territorial

Para seguir agenda, actores, señales públicas y cambios de contexto con una cadencia acordada.

Puede incluir
Alertas, seguimiento de agenda, observación de fuentes públicas y actualizaciones de escenario.
Recibís
Reportes periódicos o hitos de seguimiento según el objetivo de trabajo.
Se acuerda antes
Fuentes, frecuencia, responsables de intercambio y formato de entrega.
Consultar este alcance
04 · A medida

Relevamientos especiales

Para casos que requieren un formato, un universo de fuentes o una profundidad distinta de los servicios anteriores.

Primer paso
Una consulta breve para conocer la decisión, el contexto y el canal de respuesta.
Después
Si el caso lo requiere, se solicita un relevamiento más detallado para proponer el alcance.
Sin supuestos
No se publican casos, datos o compromisos de entrega sin autorización y acuerdo previo.
